Nova Meta

Defina o objetivo, descrição e o método de medição que o colaborador utilizará para reportar progresso.

Vincule esta meta aos pilares globais da organização para este ciclo.

Elimina fricções no reporte

Selecione o modelo mais adequado à natureza desta entrega para simplificar a apuração do resultado.

Alvo Numérico

O progresso é calculado a partir de números absolutos (ex: tickets, PRs, clientes, horas). O colaborador informa quanto realizou e o sistema calcula a porcentagem automaticamente.

Recomendado p/ métricas diretas

Binária (Marco / Projeto)

A meta é considerada por marcos claros de entrega (Não iniciada, Em andamento ou Concluída). Sem necessidade de cálculo percentual.

Ideal para projetos booleanos

Qualitativa Orientada

Para metas comportamentais ou subjetivas. Permite input percentual livre, exigindo um critério de alinhamento prévio com o gestor.

Requer rubrica de avaliação
total final
Critério de conclusão automática:

O colaborador atualizará o status escolhendo entre "Não iniciado (0%)", "Em desenvolvimento (50%)" ou "Concluído (100%)" com evidências comprobatórias anexas.

Esta instrução ficará visível para o colaborador ao preencher o progresso no ciclo.
