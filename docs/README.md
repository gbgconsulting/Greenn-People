# Documentação — Greenn People

Greenn People é uma aplicação web interna, construída 100% em Django, que centraliza o ciclo de desempenho de colaboradores: metas, avaliações, feedbacks, PDI e classificação de talentos.

Esta pasta contém os **guidelines e padrões técnicos** do projeto. Para requisitos funcionais completos, consulte o [PRD](../PRD_Greenn_People.md) na raiz do repositório.
